# Lean Pipeline 31–35 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the reach-and-retrieve lean pipeline as strategies 31–35 (auto-arm, runtime-target-ready), generated from `<30` pre-lean tuning twins (6/21/16/22), anchored to strat 6's standing core.

**Architecture:** `<30` pre-lean strats (hardcoded target+hand) are the only hand-edited cost files; a Python generator composes `{strat-6 leg-core} + {stage arm/lean overrides}` into the 31–35 cumulative-prefix ladder on every build. `lean.cc` is generalized so the counterbalance + forearm-brace cost branches read the live mocap target and auto-pick the reaching arm (the other arm braces/counterweights), exactly as the existing reach (strat 21) branch already does. The magpie gripper gets a collision proxy so the robot can't phantom through the table.

**Tech Stack:** C++ (MJPC task `lean.cc`/`lean.h`), JSON strategy files, Python generator, CMake build hook, MJCF model + unified-diff patch, MuJoCo digital twin for validation.

## Global Constraints

- **DOF invariant:** planner nq=41/nu=27, twin nq=34/nu=27 must stay byte-identical. The gripper collision proxy is a `<geom>` only — **never add a joint/DOF**.
- **Standing-core lock:** every strategy's leg-core terms = strat 6's values verbatim (`Foot Left/Right Up 2000`, `Foot Stability 15`, `Hip Yaw/Roll L/R 20`, `Lateral Center 150`, `Symmetry 200`, `Angular Momentum 5`, `Balance 2.5`, `CoM Vel. 10`, `Velocity 0.625`, `Joint Vel. 0.01`, `Joint Vel. Limit 5`, `Waist Yaw 30`, `Control 0.05`, `Posture 12`). Standing-height terms (`Base Height 450`, `Height 100`, `Knees Straight 40`) = strat-6 default; relax only at stage 34, as a named exception. Lean knobs (`Pelvis Tilt`, `Torso Forward Tilt`) + arm/task terms (`Reaching Hand Dist`, `Object Dist`, `Brace Pos`, `Brace Force`, `Contact`) are per-stage.
- **Do not change actuator limits** (no edits to `actuatorfrcrange`, joint `range`, or kp/kv gains).
- **Model edits via patch:** edit the build copy, regenerate the `.patch` via `diff -u`; never leave edits only in the build tree. Mirror to the h1_mujoco twin (`mjpc_twin` branch — make the change, do **not** commit/push).
- **Generated JSONs go to the SOURCE strategies dir** `mjpc/tasks/humanoid_bench/lean/strategies/` (the loader reads `SOURCE_DIR`, not the build tree).
- **Validation is sequential** — never run >1 `agent_server`/twin probe at once (crashes the laptop). `pkill -9 -x agent_server` before each run.
- **Faithful bench = twin at `--twin-dt 0.001`** (real 1 kHz). Lockstep over-holds — it is not a stability verdict.
- **Commits:** no `Co-Authored-By: Claude` trailer. Work on a dedicated branch/worktree (the 31–35 build rebuilds the same binary stumble-20 is being verified on).
- **Naming:** base/Magpie strategy names `h12_lean_*`; Hands variant `h12_hands_lean_*`; new pre-lean `h12_simple_forearm_brace` (+ `h12_hands_simple_forearm_brace`).

    // 2 = force RIGHT. The OTHER arm always braces/counterweights.
    int rh_id_sel = mj_name2id(model, mjOBJ_NUMERIC, "reach_hand");
    int rh_sel = (rh_id_sel >= 0)
        ? (int)std::lround(model->numeric_data[model->numeric_adr[rh_id_sel]])

                     : (data->mocap_pos[1] < torso_pos[1]);
    reaching_hand = reach_right ? right_hand_pos : left_hand_pos;
    bracing_hand  = reach_right ? left_hand_pos  : right_hand_pos;

- Produces: the 31–35 ladder JSONs in the SOURCE strategies dir, each phase = `{strat-6 core} + {stage overrides}`; cumulative prefixes; final phase `success_sustain=9999` (truncations) or finite (35); the brace phase keeps `target_ramp_sec=15`.

```python
#!/usr/bin/env python3
"""Generate the 31-35 lean pipeline JSONs from the <30 pre-lean twins.
Single source of truth: each pipeline phase = strat-6 leg-core + the stage's
arm/lean overrides. Run by the build (mjpc/tasks/CMakeLists.txt) and by hand.
"""
import json, os, copy
HERE = os.path.dirname(os.path.abspath(__file__))

def load(name): return json.load(open(os.path.join(HERE, name + ".json")))
def dump(name, phases):
    json.dump(phases, open(os.path.join(HERE, name + ".json"), "w"), indent=4)

CORE = {"Foot Left Up":2000.0,"Foot Right Up":2000.0,"Foot Stability":15.0,
        "Hip Yaw L":20.0,"Hip Roll L":20.0,"Hip Yaw R":20.0,"Hip Roll R":20.0,
        "Lateral Center":150.0,"Symmetry":200.0,"Angular Momentum":5.0,"Balance":2.5,
        "CoM Vel.":10.0,"Velocity":0.625,"Joint Vel.":0.01,"Joint Vel. Limit":5.0,
        "Waist Yaw":30.0,"Control":0.05,"Posture":12.0}
NO_CONTACT = [{"body1":-1,"body2":-1,"geom1":-1,"geom2":-1,
               "local_pos1":[0,0,0],"local_pos2":[0,0,0]} for _ in range(5)]

def phase(src_json, idx, name, sustain, ramp):
    """Build one ladder phase: src's terminal weight block, leg-core re-anchored."""
    w = copy.deepcopy(src_json[-1]["weight"])
    w.update(CORE)                      # enforce the standing-core anchor
    p = copy.deepcopy(src_json[-1])
    p["weight"] = w
    p["name"] = name
    p["success_sustain_time"] = sustain
    p["target_ramp_sec"] = ramp
    p.setdefault("contacts", NO_CONTACT)
    return p

def build(prefix):
    # prefix is "h12_" (base/magpie) or "h12_hands_" (hands). Pre-lean files are
    # "<prefix>simple_*"; generated ladder files are "<prefix>lean_*".
    stand  = load(prefix + "simple_stand")
    reach  = load(prefix + "simple_reach")
    cbal   = load(prefix + "simple_counterbalance")
    brace  = load(prefix + "simple_forearm_brace")
    # ladder phase definitions: (src, phase-name, lead-in sustain, ramp)
    P_stand = phase(stand, 0, "stand_up",                5.0, 1.5)
    P_reach = phase(reach, 1, "reach_to_target",         4.0, 2.0)
    P_cbal  = phase(cbal,  2, "counterbalance_standing", 4.0, 2.0)
    P_brace = phase(brace, 3, "forearm_brace_lean",   9999.0, 15.0)
    held = lambda p: {**copy.deepcopy(p), "success_sustain_time": 9999.0}
    out = prefix + "lean_"   # "h12_lean_" or "h12_hands_lean_"
    # cumulative-prefix ladder; last phase of each truncation is held
    dump(out + "stand",          [held(P_stand)])
    dump(out + "reach",          [P_stand, held(P_reach)])
    dump(out + "counterbalance", [P_stand, P_reach, held(P_cbal)])
    dump(out + "brace",          [P_stand, P_reach, P_cbal, held(P_brace)])
    dump(out + "full",           [P_stand, P_reach, P_cbal, P_brace])  # 35: all finite

build("h12_")          # base / magpie names: h12_lean_*
build("h12_hands_")    # hands names: h12_hands_lean_*
print("generated 31-35 ladder JSONs")
```
