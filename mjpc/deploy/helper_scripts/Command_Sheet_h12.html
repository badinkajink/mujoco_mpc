Collision-aware IK — mink QP (opt-in)

OPT-IN unvalidated

The q* solver is pluggable. Default ik_backend:=dls is the shipped damped-least-squares (joint limits only, no collision avoidance). Opt into ik_backend:=mink for QP IK that adds hard self-collision (arm ↔ torso/head/hip/left-arm) + an optional virtual table, and can stream a collision-free path instead of the straight approach. The MPC is unchanged — mink only computes the seed/path (sampling-MPC still balances + tracks). 

# one-time: install mink + a QP solver INSIDE the container
pip install mink daqp qpsolvers

# run the orchestrator on the mink backend (self-collision on):
ros2 run h12_deploy_mjpc grasp_orchestrator --ros-args -p ik_backend:=mink
# + virtual table (P3): pelvis-frame Z of the table top steers the reach AROUND the edge
  -p table_height_m:=0.78 -p table_center_xy:="[0.45, -0.15]"
# + path mode (P4): stream mink's collision-free waypoints when they bend > 3 cm off-straight
  -p ik_path_deviation_m:=0.03
